## M2 打通问答页与两套调查流程

2026-11-22 完成 M2 退出条件中的应用层和浏览器验收。运行入口与预设提问见 [README](../README.md)。

| 验收 | 实跑结果 |
| --- | --- |
| AC-03、AC-04 | FastAPI 测试客户端连接隔离 PostgreSQL。澄清零次统计，单月查数与两期比较各一次。验证显式条件覆盖默认值、追问继承与跨年推算上月。 |

`uv sync --directory backend --locked`、Ruff 检查与格式检查通过。默认 pytest **27 通过、1 跳过**，传入 `--olist-dir=../data/olist` 后 **28 通过**。前端 ESLint、Prettier、`vue-tsc` 与 Vite 构建通过，Chrome 中 Playwright **4 通过**。
