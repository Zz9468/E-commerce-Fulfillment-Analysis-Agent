# 模块地图

## M1 数据层

| 模块 | 入口和职责 | 调用方 |
| --- | --- | --- |
| [本地 PostgreSQL](../compose.yaml)、[配置示例](../.env.example) | 提供开发数据库和测试库管理连接 | 迁移、导入、pytest |
| [迁移入口](../backend/app/migrate.py)、[订单数据迁移](../backend/migrations/001_order_data.sql) | `migrate(conninfo)` 顺序应用未执行的 SQL，建立数据版本、订单事实和索引 | 本地启动、测试夹具 |
| [导入入口](../backend/scripts/import_olist.py)、[数据导入](../backend/app/import_data.py) | `import_dataset` 校验订单与客户 CSV，按原始字节哈希确定身份，在同一事务中发布版本和订单 | 导入命令、集成测试 |
| [指标查询](../backend/app/queries.py) | `compare_delivery` 和 `compare_delivery_stages` 接收调用方传入的服务端授权州，按版本和下单月份返回结构化结果 | 集成测试，M2 的工具执行层 |
| [集成测试](../backend/tests/)、[参考 SQL](../eval/reference_sql/) | 每次运行迁移隔离数据库，核对合成夹具、导入事务和 Olist 结果 | 默认回归、Olist 验收 |

问答 API、工具适配、规则与模型调查的接口与调用关系见[技术架构](技术架构.md)。

## M2 分析工作台

| 模块 | 入口和职责 |
| --- | --- |
| [API](../backend/app/main.py)、[协议](../backend/app/schemas.py) | 提供工作台元数据、提问与源证据下钻，校验入参和固定演示身份 |
| [授权与会话](../backend/app/auth.py)、[条件解析](../backend/app/conditions.py) | 按账号和数据版本保护会话证据，补全本轮、会话和页面条件 |
| [分析入口](../backend/app/analysis.py)、[工具适配](../backend/app/tools/delivery.py) | 直接查询和调查均由 `ToolRun` 校验、计数并记录 PostgreSQL 证据 |
| [调查](../backend/app/investigations.py)、[模型适配](../backend/app/model.py) | 执行规则路径、离线重放或兼容 Chat Completions 的工具循环 |
| [Vue 工作台](../frontend/src/App.vue)、[浏览器用例](../frontend/tests/workspace.spec.ts) | 维护提问和证据历史，执行城市下钻并隔离迟到响应 |
| [合成演示](../backend/scripts/seed_demo.py) | 生成可重复的集中、平稳和分散变化案例 |

## M3 数据库权限与整栈启动

| 模块 | 入口和职责 |
| --- | --- |
| [行级权限迁移](../backend/migrations/002_query_permissions.sql)、[查询连接](../backend/app/database.py) | 给总部与 SP 授予所需列和行范围，按 API 身份选择并验证只读连接，配置连接和语句超时 |
| [整栈配置](../compose.yaml)、[初始化](../backend/scripts/bootstrap_demo.py) | 等待 PostgreSQL 就绪，依次应用迁移、配置登录、发布合成数据，再启动 API 和工作台 |
| [浏览器请求](../frontend/src/api/analysis.ts)、[代理配置](../frontend/nginx.conf.template) | 配置 HTTP 超时，展示服务端状态并保留历史证据 |
