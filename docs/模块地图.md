# 模块地图

## M1 数据层

| 模块 | 入口和职责 | 调用方 |
| --- | --- | --- |
| [本地 PostgreSQL](../compose.yaml)、[配置示例](../.env.example) | 提供开发数据库和测试库管理连接 | 迁移、导入、pytest |
| [迁移入口](../backend/app/migrate.py)、[订单数据迁移](../backend/migrations/001_order_data.sql) | `migrate(conninfo)` 顺序应用未执行的 SQL，建立数据版本、订单事实和索引 | 本地启动、测试夹具 |
| [导入入口](../backend/scripts/import_olist.py)、[数据导入](../backend/app/import_data.py) | `import_dataset` 校验订单与客户 CSV，按原始字节哈希确定身份，在同一事务中发布版本和订单 | 导入命令、集成测试 |
| [指标查询](../backend/app/queries.py) | `compare_delivery` 和 `compare_delivery_stages` 接收调用方传入的服务端授权州，按版本和下单月份返回结构化结果 | 集成测试，M2 的工具执行层 |
| [集成测试](../backend/tests/)、[参考 SQL](../eval/reference_sql/) | 每次运行迁移隔离数据库，核对合成夹具、导入事务和 Olist 结果 | 默认回归、Olist 验收 |

问答 API、工具适配、规则与模型调查的接口与调用关系见[技术架构](技术架构.md)。
