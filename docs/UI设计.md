# UI 设计

交互依据见 [PRD 的主要交互](PRD.md#6-主要交互)。

## 页面布局

首版包含提问、结果与证据三个区域。提问区提供当前数据集、覆盖月份、运行模式及可见默认条件。结果区展示回答、实际查询范围、两期指标与有效样本。证据区可展开实际查询轨迹，并从州结果进入该州城市。

## 交互与页面状态

- 加载时显示分析中。切换账号、会话或数据版本后，只采用当前请求的结果。
- 澄清时集中提示缺失条件。无样本、权限受限、能力缺失和执行失败按接口状态呈现。部分结果继续显示已取得的证据。[分析接口](技术架构.md#post-apianalysis)
- 州下钻沿用所点击证据的月份与指标，服务端重新校验授权范围。页面线框和组件细节在 M2 用合成数据验证。
